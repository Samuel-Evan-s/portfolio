project detail

Diabetes Risk Classification

Machine Learning & Applied Data Science

This project explores structured tabular data modeling for classification tasks. It compares standard classification algorithms to understand model trade-offs, performance nuances, feature relevance, and evaluation metrics on medical data.

Rather than treating algorithms as black boxes, the focus was on structured experimentation, understanding data preprocessing needs, handling imbalanced distributions, and selecting appropriate metrics.

technologies
Python Scikit-learn XGBoost Pandas
key highlights
  • Comparative model evaluation across multiple classifiers
  • Feature engineering and data cleaning for structured clinical variables
  • Metrics analysis including ROC-AUC, precision, recall, and F1-score
  • Interpretability and practical performance considerations
